# AutoHub — რუკის დამოუკიდებელი ბექენდი

ეს პაკეტი ემსახურება საჯარო გეოგრაფიულ მონაცემებს. არ შეიცავს დიზაინს ან რუკის ვიზუალურ კომპონენტს. შესაძლებელია Leaflet, MapLibre, Google Maps ან ნებისმიერი ახალი ინტერფეისის დაკავშირება.

## გაშვება

საჭიროა Node.js 20.11 ან ახალი. დამატებითი პაკეტები საჭირო არ არის.

```sh
npm start
```

მისამართი: `http://127.0.0.1:8787`. შემოწმება: `npm test`.

გარემოს პარამეტრები იხილეთ `.env.example`-ში. ჩვეულებრივი `npm start` ამ ფაილს ავტომატურად არ კითხულობს. Node-ის მიერ ფაილიდან წასაკითხად გამოიყენეთ `node --env-file=.env src/server.mjs`, ან პარამეტრები ჰოსტინგის გარემოში მიუთითეთ.

## API — ვერსია 1

- `GET /health` — სერვისის მდგომარეობა.
- `GET /api/v1/layers` — ცხრა ფენა, რაოდენობები, წყაროები, მონაცემთა თარიღები და ატრიბუცია.
- `GET /api/v1/pois` — GeoJSON FeatureCollection; სავალდებულოა `bbox` ან `lat`+`lng`.

მოთხოვნის პარამეტრები:

- `layers=cameras,fuel` — ერთი ან რამდენიმე კატეგორია. ნაგულისხმევად cameras.
- `bbox=west,south,east,north` — გახსნილი რუკის საზღვრები, გრადუსებში. GeoJSON კოორდინატების რიგია `[longitude, latitude]`.
- `lat`, `lng`, `radius_m=3000` — ახლომდებარე ობიექტები, ცენტრიდან მანძილის ზრდით. რადიუსი მაქსიმუმ 100 000 მეტრია. პარკინგის პოლიგონებისთვის მანძილი გამოითვლება წარმომადგენლობით წერტილამდე და არა შესასვლელამდე.
- `q=A1043` — ძებნა სახელით, მისამართით, ბრენდით ან ოფიციალური ლოტის კოდით.
- `limit=200` — მაქსიმუმ 1 000 ობიექტი ერთ პასუხში.
- `offset=0` — შემდეგი გვერდი; პასუხში ნახეთ `meta.next_offset`.

მაგალითი:

```text
/api/v1/pois?layers=cameras,fuel,charging&bbox=44.70,41.65,44.95,41.85&limit=200
/api/v1/pois?layers=services&lat=41.7151&lng=44.8271&radius_m=5000
/api/v1/pois?layers=official-parking&bbox=44,41,45,42&q=A1043
```

პასუხში `features` არის ობიექტები; `meta` შეიცავს საერთო რაოდენობას, გვერდების პარამეტრებსა და წყაროებს. შეცდომის HTTP სტატუსებია 400 არასწორ მოთხოვნაზე, 404 უცნობ მისამართზე და 405 დაუშვებელ მეთოდზე.

## ფენები

- `cameras`: 260 კამერა/რადარი.
- `parking`: OSM-ის 2 302 პარკინგის ჩანაწერი.
- `fuel`: 1 421 ბენზინგასამართი.
- `charging`: 254 დამტენი.
- `services`: 1 344 ავტოსერვისი/საბურავების ობიექტი.
- `car-wash`: 902 ავტოსამრეცხაო.
- `parts`: 619 ნაწილების მაღაზია.
- `showrooms`: 122 ავტოსალონი.
- `official-parking`: თბილისის 2 200 მუნიციპალური ლოტის პოლიგონი და კოდი.

OSM-ის კადრი: 2026-10-27T21:23:59Z. ოფიციალური პარკინგის მიღების თარიღი: 2026-10-28. ეს ორი წყარო დამოუკიდებელია. OSM პარკინგები შესაძლოა ოფიციალურ ლოტებს ფარავდეს; ერთიან რაოდენობად მათი შეკრება ან ავტომატური გაერთიანება არ შეიძლება.

თითოეულ ობიექტს აქვს სტაბილური `id`, კატეგორია `layer`, სახელი, ხელმისაწვდომი მისამართი/ტელეფონი/საიტი/სამუშაო საათები და წყაროს დრო. არარსებული ველები არის `null` და არ გამოიგონება. `live:false` ნიშნავს, რომ ცოცხალი მდგომარეობა არ მოჰყვება. კამერებს დამატებით აქვთ `camera_kind` და `speed_limit_kmh` (მხოლოდ წყაროში რიცხვით მოცემული კმ/სთ ლიმიტისთვის). ორიგინალური OSM ტეგებიც შენარჩუნებულია.

გეოგრაფიული კონტურით აღწერილი OSM ობიექტების წერტილი მიახლოებითი ცენტრია და არა შესასვლელი. აღრიცხვა შეიძლება არასრული ან მოძველებული იყოს. ფასები, დაკავებულობა, მოქმედი ტარიფი, გადახდა და მოძრავი პატრული არ მოჰყვება. ოფიციალური პარკინგის `tariff:null` და `payment_connected:false` განზრახაა მითითებული.

## ახალ დიზაინთან მიერთება

დიზაინის შემქმნელს მიეცით ეს დოკუმენტი და `client/autohub-map-client.ts`. კლიენტი ვიზუალზე დამოკიდებული არ არის.

```ts
const api = new AutoHubMapClient('https://YOUR-API-DOMAIN');
const catalog = await api.layers();
const points = await api.pois({layers: ['cameras', 'charging'], bbox: [44.7, 41.65, 44.95, 41.85]});
```

პირველად ჩაიტვირთოს მხოლოდ კატალოგი. მონაცემები მოითხოვეთ ჩართული ფენებისთვის, რუკის გადაადგილების დასრულების შემდეგ; შეწყვიტეთ წინა მოთხოვნა AbortSignal-ით. სრული ქვეყნის ბაზის ტელეფონში ერთდროული გადმოწერა საჭირო არ არის. პარკინგის პოლიგონები ცალკე ფენად დახატეთ. ტექსტური ველები ტექსტად ჩასვით; HTML-ის სახით არ ჩასვათ. ტელეფონის/საიტის ბმულები შეამოწმეთ დასაშვები სქემებით.

## ჰოსტინგი

მზადაა Dockerfile; persistent database ამ წაკითხვის სერვისისთვის საჭირო არ არის.

```sh
docker build -t autohub-map-api .
docker run --rm -p 8787:8787 -e ALLOWED_ORIGINS=https://YOUR-SITE-DOMAIN autohub-map-api
```

საჯარო გაშვებისას გამოიყენეთ HTTPS-ის მქონე ჰოსტინგი/პროქსი. `ALLOWED_ORIGINS`-ში მიუთითეთ რეალური საიტის მისამართი. API საჯარო რუკის მონაცემებს აბრუნებს; CORS მომხმარებლის ავტორიზაცია არ არის. პასუხებს აქვს 5-წუთიანი ქეშირება, ETag და gzip. მონაცემების ფაილები იტვირთება გაშვებისას; შეცვლის შემდეგ სერვისი თავიდან გაუშვით. მაღალ ტრაფიკზე ჰოსტინგის ქეში და მოთხოვნათა შეზღუდვა ცალკე კონფიგურირდება.

ავტომატური პერიოდული განახლება ჯერ დაყენებული არ არის. განახლება: მშობელ პროექტში ჩამოტვირთეთ ახალი PBF, გაუშვით `scripts/extract-autohub-map.py`, მიღებული რვა GeoJSON და manifest გადაიტანეთ `data/`-ში, ტესტები გაუშვით და სერვისი თავიდან ააწყვეთ. ოფიციალური პარკინგის `tbilisi-parking.json` ცალკე წყაროდან განახლდება.

## არსებული სხვა სისტემები

არსებული n8n/Claude ინტეგრაციები ინარჩუნებს საკუთარ ფუნქციებს: AI მექანიკოსი, რეგისტრაცია, დიაგნოსტიკა, ჯარიმები და პარკინგის მოვლენები. ამ პაკეტში ისინი ხელახლა არ შექმნილა და მათი ცოცხალი მუშაობა ამ სამუშაოში არ მოწმდება. კერძო მანქანის/OBD მდებარეობა საჯარო რუკის API-ში არ ინახება. მოწყობილობის მიმღებსა და მომხმარებელთა პირად მონაცემებს დასჭირდება ცალკე ავტორიზებული backend, მოწყობილობის პროტოკოლის დადასტურების შემდეგ.
