# AutoHub AI - All-in-One ჭკვიანი ავტო-ჰაბი და AI დიაგნოსტიკა

სრულფასოვანი, პრემიუმ კლასის Progressive Web App (PWA) და Web Dashboard, რომელიც აერთიანებს:
1. **OBD-II რეალურ დროში დიაგნოსტიკას (ცოცხალი ტელემეტრია & 3D ავტომობილის სტუდია)**
2. **DTC შეცდომების მართვასა და „ჩეკის ჩაქრობას“ (Mode 04)**
3. **საპატრულო და ვიდეოკამერების ჯარიმების მონიტორინგს 20%-იანი ფასდაკლების ტაიმერით**
4. **მანქანის სერვის-ჟურნალსა და რესურსის პროგრეს-ბარებს**
5. **ჭკვიან ქართულენოვან AI მექანიკოსს (კონტექსტური მეხსიერებით & ხმოვანი ასისტენტით)**
6. **n8n REST Webhook-ების სრულ ინტეგრაციასა და მზა შაბლონს**

---

## 🎨 ვიზუალური სტილი და გრაფიკა (UI/UX)
- **3D ინტერაქტიული სტუდია (Three.js):** 3D ავტომობილის მოდელი PBR განათებით, რბილი ჩრდილებით და ინტერაქტიული 3D პინ-მარკერებით (ძრავა, O2 სენსორი, სამუხრუჭე ხუნდები, აკუმულატორი, საბურავები).
- **ერთი შეხებით ლაზერული სკანირება:** ლაზერის სხივის ანიმაცია და Web Audio API ხმოვანი ეფექტები.
- **Glassmorphism & Claymorphism:** macOS-ის სტილის დახვეწილი ფანჯრები, ქართული თანამედროვე ტიპოგრაფია.
- **საქართველოს სახელმწიფო ნომრის ვიზუალიზაცია** და საპატრულო ჯარიმების 20%-იანი საშეღავათო ვადის Countdown ტაიმერი.

## ⚡ n8n Webhook ინტეგრაცია (Backend Contracts)
აპლიკაცია n8n-თან ურთიერთობს 4 მთავარი REST Webhook-ით:

1. **`POST /webhook/obd-scan`**
   - **Input:** `{ "raw_data": "43 01 33 00 00", "vehicle_id": "CAR_01" }`
   - **Output:** `{ "parsed_codes": [{"code": "P0133", "title_ge": "...", "severity": "medium", "safe_to_drive": true, "advice": "..."}] }`

2. **`POST /webhook/clear-codes`**
   - **Input:** `{ "command": "04", "vehicle_id": "CAR_01" }`
   - **Output:** `{ "status": "success", "message": "შეცდომები წარმატებით წაიშალა" }`

3. **`POST /webhook/ai-mechanic-chat`**
   - **Input:** `{ "message": "რა ჯდება ამ სენსორის შეცვლა?", "car_context": {...} }`
   - **Output:** `{ "reply": "სავარაუდო ღირებულება თბილისის ბაზარზე..." }`

4. **`POST /webhook/fines-check`**
   - **Input:** `{ "plate_number": "GE-777-AA", "tech_passport": "AA9876543" }`
   - **Output:** `{ "fines": [...] }`

### მზა n8n Workflow შაბლონი
ფაილი მდებარეობს `public/n8n-workflow-template.json`-ში. შეგიძლიათ ერთი დაკლიკებით ჩამოტვირთოთ აპლიკაციის პარამეტრებიდან და დააიმპორტოთ n8n-ში.

## 📱 PWA მხარდაჭერა
- სრული Offline Fallback (`public/sw.js` Service Worker).
- `public/manifest.json` და დაინსტალირების ღილაკი Home Screen-ზე დასამატებლად.
- LocalStorage ავტომატური სინქრონიზაცია მანქანის პროფილისთვის, DTC შეცდომებისთვის, ჯარიმებისთვის და სერვისის ისტორიისთვის.
